Observables → media Y varianza

Las variables con E[X] ≠ 0 (antigüedad, exportadora, formalidad) desplazan la media del outcome via β·E[X]/(1−ρ). Ese mismo β también genera varianza: β²·Var[X]/(1−ρ)². Con ρ alto el multiplicador amplifica ambos efectos simultáneamente, por eso el presupuesto de media y el presupuesto de varianza están acoplados.

El evaluador puede controlar por estas variables → no generan sesgo de selección por sí solas.

No observables → solo varianza + confounding

Las variables con E[X] = 0 (calidad_gerencial, productividad_latente) no afectan la media de Y* pero sí su varianza: β²/(1−ρ)². Lo crítico: estas mismas variables entran en el propensity score.

Resultado: las firmas con mayor calidad gerencial tienen mejores outcomes de base y mayor probabilidad de participar. El evaluador no puede controlar por esto → fuente principal de sesgo de selección. El % no-obs en la barra de varianza calibra la dificultad del problema de identificación.

Elegibilidad dinámica → feedback outcome → selección

La condición empleados ∈ [3, 100] usa el valor del período actual, no las características fijas. Como empleados evoluciona via AR(1), el historial de shocks determina si la firma está en el pool de candidatas en cada cohorte.

Esto crea un loop: Y(t−1) → elegibilidad(t) → tratamiento(t) → Y(t). La fracción elegible (caja verde en resultados) depende de dónde cae la distribución estacionaria respecto al intervalo [3, 100]. Si es >80%, el criterio no selecciona; si es <20%, casi no hay candidatos.
